# AI-Based Virtual Squat Assistant
# made with my team.

## About the Project
The AI-Based Virtual Squat Assistant is a real-time exercise assistant that uses computer vision to detect squat poses, count repetitions, and provide voice feedback to help users perform squats correctly.

## Features
- Real-time pose detection using a webcam
- AI-based squat posture analysis
- Automatic squat repetition counting
- Voice feedback for posture correction
- Real-time exercise monitoring

## Technologies Used
- Python
- OpenCV
- MediaPipe
- Text-to-Speech (TTS)
- Computer Vision

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Connect or enable your webcam.
4. Run the Python program.
